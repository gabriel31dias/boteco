# Pôquer Texas Hold'em (Sit & Go online) — Plano de Implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Novo jogo "Pôquer" no Boteco: Texas Hold'em No-Limit online via Socket.IO, de 2 a 6 jogadores, num formato Sit & Go (todos pagam a entrada, recebem 1.500 fichas, e quem ficar com todas as fichas leva o pote em dinheiro). A mesa é animada e imersiva, abre em tela cheia e deitada automaticamente, igual à sinuca.

**Architecture:** Igual aos outros jogos arbitrados: um processo por jogo (`JOGO=poker`, porta 3009, caminho `/ws/poker`). O servidor é dono do baralho e das apostas e manda um payload por assento, então a mão dos outros nunca sai do servidor. As regras são puras e compartilhadas: `src/games/poker/regras.js` (avaliador de mãos) e `src/games/poker/mesa.js` (uma mão de apostas, com side pots). O torneio (blinds subindo, relógio, eliminação) fica em `server/jogos/poker.js`. O cliente é React DOM com framer-motion, com a mesa desenhada em CSS e sprites recortados do kit de assets.

**Tech Stack:** Node 22+ (`node:sqlite`), socket.io 4, React 19, framer-motion, canvas-confetti, Tailwind, WebAudio sintetizado. Nenhuma dependência nova.

**Spec:** não existe documento separado: os requisitos vieram da conversa e estão em "Global Constraints". Referências visuais: `~/Downloads/Mesa de Pôquer Cinematográfica com Cartas e Fichas (1).png` (layout da mesa) e `~/Downloads/Kit de Assets para Poker e Cassino.png` (sprites).

## Regras pesquisadas (o que a engine implementa)

Fontes: Poker TDA Rules (regras 46 e 47 e o fórum oficial), PokerStrategy (all-in), PokerTH e DeucesCracked (ranking).

1. **Mão:** cada jogador recebe 2 cartas fechadas. A mesa abre 5 comunitárias: flop (3), turn (1) e river (1), queimando 1 carta antes de cada rua. Vale a melhor combinação de 5 entre as 7 cartas (pode usar 0, 1 ou 2 das fechadas).
2. **Ranking:** Straight flush (o Royal é o mais alto) > Quadra > Full house > Flush > Sequência > Trinca > Dois pares > Par > Carta alta. **A-2-3-4-5 é a menor sequência**: o 5 é a carta alta, e o mesmo vale para o straight flush "steel wheel". O Ás nunca dá a volta (Q-K-A-2-3 não é sequência). **Naipe nunca desempata.** Empate exato divide o pote. Kicker decide entre categorias iguais, sempre olhando só as 5 cartas da mão.
3. **Botão e blinds:** o SB é o primeiro à esquerda do botão e o BB o seguinte. **No mano a mano (heads-up), o botão é o SB**, age primeiro no pré-flop e por último nas ruas seguintes. Quem não tem fichas para o blind inteiro posta o que tem e fica all-in.
4. **Ordem de ação:** no pré-flop começa o primeiro depois do BB, e o BB tem a "opção" de aumentar mesmo se todos só pagaram. Do flop em diante começa o primeiro jogador ativo à esquerda do botão.
5. **Aposta mínima (TDA 46):** a primeira aposta da rua é de pelo menos 1 BB. Um raise tem que subir pelo menos o tamanho do maior bet ou raise da rua. All-ins curtos não mudam esse mínimo.
6. **All-in curto não reabre a ação (TDA 47):** se um all-in sobe menos que um raise completo, quem já tinha agido só pode pagar ou largar. Quem ainda não agiu pode aumentar normalmente.
7. **Side pots:** cada nível de investimento forma um pote, e só disputa um pote quem investiu até aquele nível e não largou. O excedente que ninguém pagou volta para quem apostou (é um pote com um único elegível).
8. **Showdown:** todo pote disputado é dividido entre os melhores das mãos elegíveis. **A ficha ímpar vai para o primeiro vencedor à esquerda do botão.** Quando todos largam, o último que sobra leva tudo sem mostrar as cartas.
9. **Torneio (Sit & Go):** 1.500 fichas por jogador. Os blinds sobem a cada 3 minutos (tabela em `NIVEIS`). Quem fica sem fichas é eliminado, e o último com fichas leva o pote em dinheiro (`settleMatch`). O botão anda para o próximo jogador com fichas (é o "moving button": simplificação documentada do "dead button" da TDA).
10. **Relógio online:** são 20s por ação. Se estourar, o jogo dá check quando pode e fold quando não pode. Com 3 estouros seguidos o jogador é eliminado (para um ausente não travar a mesa). Sair da mesa é eliminação: a mão dele foi largada, e o que ele já pôs no pote fica lá.

## Global Constraints

- Jogo id `poker`, porta `3009`, caminho de socket `/ws/poker`, script `npm run server:poker`, incluído em `npm run servers`.
- Mesa de 2 a 6 jogadores: `minJogadores: 2`, `maxJogadores: 6`, `esperaMs: 15_000` (cheia, abre na hora).
- Dinheiro: o vencedor leva o pote (`prize * n / 2`, a mesma regra do dominó individual). As salas são as mesmas (`treino`, `bronze`, `prata`, `ouro`, `privada`).
- Fichas do torneio não são dinheiro: só a colocação final mexe no saldo.
- O servidor nunca manda as cartas fechadas de outro assento antes do showdown, nem o baralho.
- Tela: abre em tela cheia (`.bt-partida`) e, no celular em pé, gira para paisagem com a classe `mesa-girada`, como a sinuca.
- Sem dependências novas: framer-motion, canvas-confetti e lucide-react já estão instalados.
- Textos da interface em português do Brasil e valores no formato `R$ 3,60`.
- Código no estilo do repo: comentários em português explicando o *porquê*, ESM e `ponytail:` nas simplificações.

```js
import { mulberry32 } from '../domino/regras.js';

/**
 * Regras puras do Texas Hold'em: baralho e avaliador. Roda igual no servidor
 * (que decide) e no cliente (que só mostra "Par de Reis" pra você).
 * Carta = 'As' (valor + naipe). Valor: 23456789TJQKA. Naipe: s h d c.
 */
export { mulberry32 };
export const VALORES = '23456789TJQKA';
export const NAIPES = 'shdc';
export const CATEGORIAS = ['Carta alta', 'Par', 'Dois pares', 'Trinca', 'Sequência', 'Flush',
  'Full house', 'Quadra', 'Straight flush'];
const PLURAL = { 14: 'Ases', 13: 'Reis', 12: 'Damas', 11: 'Valetes', 10: 'Dez', 9: 'Noves', 8: 'Oitos',
  7: 'Setes', 6: 'Seis', 5: 'Cincos', 4: 'Quatros', 3: 'Três', 2: 'Dois' };

export const baralho = () => [...NAIPES].flatMap((n) => [...VALORES].map((v) => v + n));

/** Fisher–Yates com o rng dado: a semente reproduz a mão nos testes. */
export function embaralhar(cartas, rng) {
  const c = [...cartas];
  for (let i = c.length - 1; i > 0; i--) {
    const j = Math.floor(rng() * (i + 1));
    [c[i], c[j]] = [c[j], c[i]];
  }
  return c;
}

const valor = (carta) => VALORES.indexOf(carta[0]) + 2;

/** Força de exatamente 5 cartas: [categoria, ...desempate], comparável em ordem. */
function avaliar5(c) {
  const vs = c.map(valor).sort((a, b) => b - a);
  const flush = c.every((x) => x[1] === c[0][1]);
  const unicos = [...new Set(vs)];
  let topo = 0;
  if (unicos.length === 5) {
    if (vs[0] - vs[4] === 4) topo = vs[0];
    else if (vs.join() === '14,5,4,3,2') topo = 5;     // roda: o Ás vale 1
  }
  // Grupos por quantidade e depois por valor: [3,3,3,2,2] vira trinca de 3 com par de 2.
  const grupos = unicos.map((v) => [vs.filter((x) => x === v).length, v]).sort((a, b) => b[0] - a[0] || b[1] - a[1]);
  const porGrupo = grupos.map((g) => g[1]);
  const [g0, g1] = [grupos[0][0], grupos[1]?.[0]];
  if (topo && flush) return [8, topo];
  if (g0 === 4) return [7, ...porGrupo];
  if (g0 === 3 && g1 === 2) return [6, ...porGrupo];
  if (flush) return [5, ...vs];
  if (topo) return [4, topo];
  if (g0 === 3) return [3, ...porGrupo];
  if (g0 === 2 && g1 === 2) return [2, ...porGrupo];
  if (g0 === 2) return [1, ...porGrupo];
  return [0, ...vs];
}

export function comparar(a, b) {
  for (let i = 0; i < Math.max(a.length, b.length); i++) {
    const d = (a[i] ?? 0) - (b[i] ?? 0);
    if (d) return d;
  }
  return 0;
}

function* combinacoes(arr, k, de = 0, atual = []) {
  if (atual.length === k) { yield atual; return; }
  for (let i = de; i <= arr.length - (k - atual.length); i++) yield* combinacoes(arr, k, i + 1, [...atual, arr[i]]);
}

function nomeDe([cat, a, b]) {
  if (cat === 8 && a === 14) return 'Royal flush';
  if (cat === 1) return `Par de ${PLURAL[a]}`;
  if (cat === 2) return `Dois pares, ${PLURAL[a]} e ${PLURAL[b]}`;
  if (cat === 3) return `Trinca de ${PLURAL[a]}`;
  if (cat === 7) return `Quadra de ${PLURAL[a]}`;
  return CATEGORIAS[cat];
}

/**
 * Melhor mão de 5 entre 5 a 7 cartas. ponytail: força bruta nas 21
 * combinações; sobra velocidade pra uma mesa de 6 (avaliador por tabela
 * só se um dia isso aparecer no profiler).
 */
export function avaliar(cartas) {
  if (!cartas || cartas.length < 5) return null;
  let melhor = null;
  for (const c of combinacoes(cartas, 5)) {
    const forca = avaliar5(c);
    if (!melhor || comparar(forca, melhor.forca) > 0) melhor = { forca, melhores: c };
  }
  return { ...melhor, nome: nomeDe(melhor.forca) };
}
```

```js
import { avaliar, baralho, comparar, embaralhar } from './regras.js';

/**
 * Uma mão de Texas Hold'em No-Limit: blinds, quatro ruas de aposta, side pots
 * e showdown. Pura (sem relógio, sem socket): o árbitro do servidor chama
 * agir() e lê os campos. Regras da TDA — ver docs/superpowers/plans/2026-10-09-poker.md.
 *
 * Fichas são inteiros. `pilha` é o que está atrás da linha; `aposta` é o que
 * foi posto nesta rua; `investido` é o total da mão (é dele que saem os potes).
 */
export class Mao {
  constructor({ fichas, botao, sb, bb, rng = Math.random }) {
    this.n = fichas.length;
    this.pilha = [...fichas];
    this.ativo = fichas.map((f) => f > 0);
    this.botao = botao;
    this.sb = sb;
    this.bb = bb;
    this.aposta = Array(this.n).fill(0);
    this.investido = Array(this.n).fill(0);
    this.foldou = Array(this.n).fill(false);
    this.jaAgiu = Array(this.n).fill(false);
    this.pendentes = new Set();
    this.board = [];
    this.resultado = null;
    this.fase = 'preflop';

    // Distribui uma por vez a partir da esquerda do botão, como na mesa de verdade.
    this.deck = embaralhar(baralho(), rng);
    this.cartas = this.pilha.map(() => null);
    const ordem = this.desde(this.prox(botao));
    for (const s of ordem) this.cartas[s] = [this.deck.pop()];
    for (const s of ordem) this.cartas[s].push(this.deck.pop());

    // Heads-up: o botão é o SB (e age primeiro no pré-flop).
    this.posSb = ordem.length === 2 ? botao : this.prox(botao);
    this.posBb = this.prox(this.posSb);
    this.pagar(this.posSb, sb);
    this.pagar(this.posBb, bb);
    this.maior = Math.max(...this.aposta);
    this.minRaise = bb;
    this.abrirRodada(this.prox(this.posBb));
  }

  /** Próximo assento que recebeu cartas, no sentido horário. */
  prox(s) {
    for (let i = 1; i <= this.n; i++) { const x = (s + i) % this.n; if (this.ativo[x]) return x; }
    return s;
  }

  /** Assentos com cartas, começando em `s`. */
  desde(s) {
    const r = [];
    for (let i = 0; i < this.n; i++) { const x = (s + i) % this.n; if (this.ativo[x]) r.push(x); }
    return r;
  }

  vivos() { return this.desde(0).filter((s) => !this.foldou[s]); }
  podeAgir(s) { return this.ativo[s] && !this.foldou[s] && this.pilha[s] > 0; }

  pagar(s, valor) {
    const v = Math.min(valor, this.pilha[s]);
    this.pilha[s] -= v;
    this.aposta[s] += v;
    this.investido[s] += v;
    return v;
  }

  abrirRodada(primeiro) {
    this.jaAgiu.fill(false);
    this.pendentes = new Set(this.desde(0).filter((s) => this.podeAgir(s)));
    // Todo mundo all-in menos um que já cobriu: não há o que decidir.
    if (this.pendentes.size === 1) {
      const [x] = this.pendentes;
      if (this.aposta[x] >= this.maior) this.pendentes.clear();
    }
    this.vez = this.desde(primeiro).find((s) => this.pendentes.has(s)) ?? null;
    if (this.vez === null) this.avancarRua();
  }

  acoesLegais(s) {
    if (this.fase === 'fim' || s !== this.vez) return null;
    const falta = this.maior - this.aposta[s];
    const total = this.aposta[s] + this.pilha[s];
    // TDA 47: quem já agiu e só encara um all-in curto não reabre.
    const podeAumentar = !this.jaAgiu[s] && total > this.maior;
    return {
      check: falta === 0,
      call: falta > 0 ? Math.min(falta, this.pilha[s]) : 0,
      minRaise: podeAumentar ? Math.min(this.maior + this.minRaise, total) : null,
      maxRaise: podeAumentar ? total : null,
    };
  }

  agir(s, { tipo, valor } = {}) {
    const L = this.acoesLegais(s);
    if (!L) throw new Error('fora da vez');
    let ev;
    if (tipo === 'fold') {
      this.foldou[s] = true;
      ev = { tipo: 'fold' };
    } else if (tipo === 'check') {
      if (!L.check) throw new Error('check inválido');
      ev = { tipo: 'check' };
    } else if (tipo === 'call' || (tipo === 'allin' && L.minRaise === null)) {
      if (!L.call) { if (L.check) return this.agir(s, { tipo: 'check' }); throw new Error('call inválido'); }
      this.pagar(s, L.call);
      ev = { tipo: this.pilha[s] === 0 ? 'allin' : 'call', valor: this.aposta[s] };
    } else if (tipo === 'raise' || tipo === 'allin') {
      const para = tipo === 'allin' ? L.maxRaise : Math.floor(Number(valor));
      if (L.minRaise === null || !Number.isFinite(para) || para < L.minRaise || para > L.maxRaise) {
        throw new Error('aposta inválida');
      }
      const abriu = this.maior === 0;
      const aumento = para - this.maior;
      this.pagar(s, para - this.aposta[s]);
      if (aumento >= this.minRaise) { this.minRaise = aumento; this.jaAgiu.fill(false); }
      this.maior = para;
      for (const x of this.desde(0)) if (x !== s && this.podeAgir(x)) this.pendentes.add(x);
      ev = { tipo: this.pilha[s] === 0 ? 'allin' : abriu ? 'bet' : 'raise', valor: para };
    } else {
      throw new Error('ação inválida');
    }
    this.jaAgiu[s] = true;
    this.pendentes.delete(s);
    this.seguir(s);
    return ev;
  }

  /** Sai da mesa no meio da mão: larga sem mexer na vez de ninguém. */
  abandonar(s) {
    if (this.fase === 'fim' || !this.ativo[s] || this.foldou[s]) return;
    if (this.vez === s) { this.agir(s, { tipo: 'fold' }); return; }
    this.foldou[s] = true;
    this.pendentes.delete(s);
    if (this.vivos().length === 1) this.encerrar();
  }

  seguir(s) {
    if (this.vivos().length === 1) return this.encerrar();
    if (this.pendentes.size === 0) return this.avancarRua();
    this.vez = this.desde(this.prox(s)).find((x) => this.pendentes.has(x));
  }

  avancarRua() {
    this.vez = null;
    if (this.fase === 'river') return this.showdown();
    const [prox, qtd] = { preflop: ['flop', 3], flop: ['turn', 1], turn: ['river', 1] }[this.fase];
    this.deck.pop();                                  // queima
    for (let i = 0; i < qtd; i++) this.board.push(this.deck.pop());
    this.fase = prox;
    this.aposta.fill(0);
    this.maior = 0;
    this.minRaise = this.bb;
    // Menos de dois podendo apostar: o board corre sozinho até o river.
    if (this.desde(0).filter((x) => this.podeAgir(x)).length < 2) return this.avancarRua();
    this.abrirRodada(this.prox(this.botao));
  }

  /** Potes por nível de investimento. Quem largou paga, mas não disputa. */
  potes() {
    const niveis = [...new Set(this.investido.filter((v) => v > 0))].sort((a, b) => a - b);
    const potes = [];
    let anterior = 0;
    let sobra = 0;                                   // nível só de quem largou: vai pro pote seguinte
    for (const nivel of niveis) {
      const pagaram = this.desde(0).filter((s) => this.investido[s] >= nivel);
      const valor = (nivel - anterior) * pagaram.length + sobra;
      const elegiveis = pagaram.filter((s) => !this.foldou[s]);
      anterior = nivel;
      if (!elegiveis.length) { if (potes.length) potes.at(-1).valor += valor; else sobra = valor; continue; }
      sobra = 0;
      const igual = potes.at(-1);
      if (igual && igual.elegiveis.join() === elegiveis.join()) igual.valor += valor;
      else potes.push({ valor, elegiveis });
    }
    return potes;
  }

  encerrar() {
    const [w] = this.vivos();
    const total = this.investido.reduce((a, b) => a + b, 0);
    const ganhos = Array(this.n).fill(0);
    ganhos[w] = total;
    this.pilha[w] += total;
    this.resultado = { potes: [{ valor: total, elegiveis: [w], vencedores: [w] }], ganhos, mostradas: null, maos: null };
    this.fase = 'fim';
    this.vez = null;
  }

  showdown() {
    const vivos = this.vivos();
    const mao = Object.fromEntries(vivos.map((s) => [s, avaliar([...this.cartas[s], ...this.board])]));
    const ganhos = Array(this.n).fill(0);
    const esquerda = this.desde(this.prox(this.botao));
    const potes = this.potes().map(({ valor, elegiveis }) => {
      let melhor = null;
      let vencedores = [];
      for (const s of elegiveis) {
        const c = melhor ? comparar(mao[s].forca, melhor) : 1;
        if (c > 0) { melhor = mao[s].forca; vencedores = [s]; } else if (c === 0) vencedores.push(s);
      }
      // Ficha ímpar: primeiro vencedor à esquerda do botão.
      vencedores = esquerda.filter((s) => vencedores.includes(s));

      for (const s of vencedores) ganhos[s] += parte + (resto-- > 0 ? 1 : 0);
      return { valor, elegiveis, vencedores };
    });
    for (let s = 0; s < this.n; s++) this.pilha[s] += ganhos[s];
    this.resultado = {
      potes, ganhos,
      mostradas: Object.fromEntries(vivos.map((s) => [s, this.cartas[s]])),
      maos: Object.fromEntries(vivos.map((s) => [s, { nome: mao[s].nome, melhores: mao[s].melhores }])),
    };
    this.fase = 'fim';
    this.vez = null;
  }
}
```

```js
import { Mao } from '../../src/games/poker/mesa.js';
import { avaliar } from '../../src/games/poker/regras.js';

/**
 * Árbitro do pôquer: Sit & Go de Texas Hold'em. Todos pagam a entrada, cada
 * um recebe FICHAS, e quem ficar com todas leva o pote em dinheiro — encaixa
 * no settleMatch de um vencedor só, sem mexer na economia.
 *
 * A mão em si é a Mao (regras puras). Aqui entram o que é de torneio: blinds
 * que sobem com o tempo, relógio, botão andando, eliminação e sigilo.
 */
export const FICHAS = 1500;
export const NIVEIS = [[10, 20], [15, 30], [25, 50], [50, 100], [75, 150], [100, 200], [150, 300],
  [200, 400], [300, 600], [400, 800], [600, 1200], [1000, 2000]];
export const TEMPO_NIVEL = Number(process.env.POKER_NIVEL) || 180_000;
export const TEMPO_JOGADA = Number(process.env.POKER_TEMPO) || 20_000;
export const PAUSA_MAO = Number(process.env.POKER_PAUSA ?? 4000);   // showdown na tela antes da próxima
export const AUSENCIAS_MAX = 3;

const nivelDe = (p) => Math.min(NIVEIS.length - 1, Math.floor((Date.now() - p.inicio) / TEMPO_NIVEL));

export function novaPartida(jogadores = 2) {
  const p = {
    n: jogadores, fichas: Array(jogadores).fill(FICHAS), botao: Math.floor(Math.random() * jogadores),
    inicio: Date.now(), maoNum: 0, mao: null, desde: Date.now(), vez: null, fim: null,
    ausencias: Array(jogadores).fill(0), saiu: Array(jogadores).fill(false), colocacao: [],
  };
  novaMao(p, true);
  return p;
}

/** Botão anda pro próximo com fichas (moving button: mais simples que o dead button da TDA). */
function novaMao(p, primeira = false) {
  if (!primeira) {
    for (let i = 1; i <= p.n; i++) { const x = (p.botao + i) % p.n; if (p.fichas[x] > 0) { p.botao = x; break; } }
  }
  const [sb, bb] = NIVEIS[nivelDe(p)];
  p.mao = new Mao({ fichas: p.fichas, botao: p.botao, sb, bb });
  p.maoNum++;
  p.desde = Date.now();
  depois(p, null);
}

/** Depois de qualquer mudança: fecha a mão, elimina quem zerou e vê se acabou. */
function depois(p, r) {
  const m = p.mao;
  if (m.fase === 'fim') {
    p.fichas = m.pilha.map((f, s) => (p.saiu[s] ? 0 : f));
    for (let s = 0; s < p.n; s++) if (!p.fichas[s] && !p.colocacao.includes(s)) p.colocacao.push(s);
    const restam = p.fichas.flatMap((f, s) => (f > 0 ? [s] : []));
    if (restam.length === 1 && !p.fim) {
      const motivo = r?.tipo === 'tempo' ? 'tempo' : r?.tipo === 'saiu' ? 'abandono' : 'fichas';
      p.fim = { vencedor: restam[0], motivo };
    }
    if (r) r = { ...r, mao: m.resultado };
  }
  p.vez = m.fase === 'fim' ? null : m.vez;
  return r;
}

export const restante = (p) => Math.max(0, p.desde + (p.mao.fase === 'fim' ? PAUSA_MAO : TEMPO_JOGADA) - Date.now());

export function agir(p, assento, { tipo, valor } = {}) {
  if (p.fim || p.mao.fase === 'fim') return null;
  let ev;
  try { ev = p.mao.agir(assento, { tipo, valor }); } catch { return null; }   // regra recusou: nada muda
  p.ausencias[assento] = 0;
  p.desde = Date.now();
  return depois(p, { tipo: 'acao', assento, acao: ev.tipo, valor: ev.valor });
}

/** O relógio venceu: fim da pausa abre a próxima mão; senão, quem está na vez. */
export function estourou(p) {
  if (p.fim) return null;
  if (p.mao.fase === 'fim') { novaMao(p); return { tipo: 'novaMao' }; }
  const s = p.mao.vez;
  if (++p.ausencias[s] >= AUSENCIAS_MAX) return eliminar(p, s, 'tempo');
  const ev = p.mao.agir(s, { tipo: p.mao.acoesLegais(s).check ? 'check' : 'fold' });
  p.desde = Date.now();
  return depois(p, { tipo: 'tempo', assento: s, acao: ev.tipo });
}

/**
 * Saiu (ou sumiu): larga a mão e, quando ela fechar, fica sem fichas. O que
 * já pôs no pote fica lá. Sobrou um com fichas: ele leva.
 */
export function eliminar(p, assento, motivo = 'abandono') {
  if (p.fim || p.saiu[assento]) return null;
  p.saiu[assento] = true;
  const antes = p.mao.vez;
  p.mao.abandonar(assento);
  // A mão segue sem ele: as fichas que sobraram atrás da linha somem agora (o
  // que ele pôs no pote fica). Se a mão fechou no abandonar, depois() zera.
  if (p.mao.fase !== 'fim') {
    p.mao.pilha[assento] = 0;
    if (!p.colocacao.includes(assento)) p.colocacao.push(assento);
  }
  if (p.mao.vez !== antes) p.desde = Date.now();
  const tipo = motivo === 'tempo' ? 'tempo' : 'saiu';
  return depois(p, { tipo, assento });
}

/** Só o que este assento pode ver. Cartas dos outros: só no showdown. */
export const estadoPara = (p, assento) => {
  const m = p.mao;
  const fim = m.fase === 'fim';
  const nivel = nivelDe(p);
  const minhas = m.cartas[assento];
  return {
    assento, jogadores: p.n, maoNum: p.maoNum, fase: m.fase,
    fichas: m.pilha, apostas: m.aposta, investido: m.investido,
    pote: m.investido.reduce((a, b) => a + b, 0),
    potes: fim ? m.resultado.potes : m.potes(),
    board: m.board, minhas,
    minhaMao: minhas && m.board.length >= 3 ? avaliar([...minhas, ...m.board]).nome : null,
    cartas: fim ? m.resultado.mostradas : null,
    maos: fim ? m.resultado.maos : null,
    ganhos: fim ? m.resultado.ganhos : null,
    ativos: m.ativo, foldou: m.foldou, saiu: p.saiu,
    botao: m.botao, posSb: m.posSb, posBb: m.posBb, sb: m.sb, bb: m.bb,
    nivel: nivel + 1, proximoNivel: NIVEIS[nivel + 1] ?? null, proximoNivelEm: p.inicio + (nivel + 1) * TEMPO_NIVEL,
    vez: p.vez, legais: m.acoesLegais(assento),
    prazo: p.desde + (fim ? PAUSA_MAO : TEMPO_JOGADA),
    colocacao: p.colocacao, fim: p.fim,
  };
};
```

```js
// quem age depois de você fica à sua esquerda, que é a esquerda da tela.
const LUGARES = {
  2: [[50, 82], [50, 12]],
  3: [[50, 82], [16, 26], [84, 26]],
  4: [[50, 82], [9, 48], [50, 12], [91, 48]],
  5: [[50, 82], [11, 64], [22, 15], [78, 15], [89, 64]],
  6: [[50, 82], [11, 68], [11, 28], [50, 12], [89, 28], [89, 68]],

export function lugarDe(assento, eu, n) {
  const [x, y] = LUGARES[n][(assento - eu + n) % n];
  return { x, y };
}

const DENOMINACOES = [[1000, 'dourada'], [100, 'preta'], [25, 'verde'], [10, 'azul'], [5, 'vermelha'], [1, 'branca']];

export function fichasDe(valor) {
  const r = [];

  for (const [v, cor] of DENOMINACOES) while (resto >= v && r.length < 10) { r.push(cor); resto -= v; }
  return r;
}

/** Atalhos do aumento: mínimo, ½ pote, pote, all-in — sempre dentro do permitido. */
export function presets(L, pote, apostaAtual) {
  if (L?.minRaise == null) return [];
  const limita = (v) => Math.max(L.minRaise, Math.min(L.maxRaise, Math.round(v)));
  const potePos = pote + L.call;                       // pote depois de pagar
  const lista = [
    { rotulo: 'Mín', valor: L.minRaise },
    { rotulo: '½ Pote', valor: limita(apostaAtual + L.call + potePos / 2) },
    { rotulo: 'Pote', valor: limita(apostaAtual + L.call + potePos) },
  ];
  // Valor repetido some; o All-in sempre fica (é o botão que todo mundo procura).
  const unicos = lista.filter((p, i) => p.valor !== L.maxRaise && lista.findIndex((q) => q.valor === p.valor) === i);
  return [...unicos, { rotulo: 'All-in', valor: L.maxRaise }];
}

const ROTULOS = { fold: 'LARGOU', check: 'CHECK', call: 'PAGOU', bet: 'APOSTOU', raise: 'AUMENTOU', allin: 'ALL-IN!' };
export const rotulo = (ev) => (ev.acao === 'allin' || ev.acao === 'fold' || ev.acao === 'check'
  ? ROTULOS[ev.acao] : `${ROTULOS[ev.acao]} ${ev.valor}`);

export const brl = (centavos) => `R$ ${(centavos / 100).toFixed(2).replace('.', ',')}`;
```

```js
/**
 * Efeitos do pôquer, sintetizados (nenhum arquivo): ruído filtrado pra carta
 * e ficha, seno pra UI. ponytail: WebAudio direto, igual ao truco.
 */
class Sound {
  enabled = true;
  ctx = null;

  pronto() {
    if (!this.enabled) return null;
    if (!this.ctx) {
      const AC = window.AudioContext || window.webkitAudioContext;
      if (!AC) return null;
      this.ctx = new AC();
    }
    if (this.ctx.state === 'suspended') this.ctx.resume();
    return this.ctx;
  }

  ruido(dur, freq, vol = 0.4, atraso = 0) {
    const c = this.pronto(); if (!c) return;
    const t = c.currentTime + atraso;
    const buf = c.createBuffer(1, c.sampleRate * dur, c.sampleRate);
    const d = buf.getChannelData(0);
    for (let i = 0; i < d.length; i++) d[i] = (Math.random() * 2 - 1) * (1 - i / d.length) ** 2;
    const src = c.createBufferSource(); src.buffer = buf;
    const f = c.createBiquadFilter(); f.type = 'bandpass'; f.frequency.value = freq;
    const g = c.createGain(); g.gain.value = vol;
    src.connect(f).connect(g).connect(c.destination);
    src.start(t);
  }

  tom(freq, dur, vol = 0.15, atraso = 0, tipo = 'sine') {
    const c = this.pronto(); if (!c) return;
    const t = c.currentTime + atraso;
    const o = c.createOscillator(); o.type = tipo; o.frequency.value = freq;
    const g = c.createGain();
    g.gain.setValueAtTime(vol, t); g.gain.exponentialRampToValueAtTime(0.001, t + dur);
    o.connect(g).connect(c.destination); o.start(t); o.stop(t + dur);
  }

  carta(atraso = 0) { this.ruido(0.08, 2500, 0.35, atraso); }
  ficha(qtd = 3) { for (let i = 0; i < qtd; i++) this.ruido(0.05, 5200 + i * 300, 0.3, i * 0.045); }
  check() { this.ruido(0.06, 300, 0.6); this.ruido(0.06, 300, 0.6, 0.12); }   // duas batidinhas na mesa
  fold() { this.ruido(0.18, 1200, 0.25); }
  allin() { this.ficha(8); this.tom(110, 0.6, 0.2, 0, 'sawtooth'); }
  suaVez() { this.tom(880, 0.12); this.tom(1320, 0.18, 0.12, 0.1); navigator.vibrate?.(40); }
  tick() { this.tom(1000, 0.05, 0.08); }
  vitoria() { [523, 659, 784, 1047].forEach((f, i) => this.tom(f, 0.35, 0.18, i * 0.12, 'triangle')); }
}

export const sound = new Sound();
```
